JUST Smart Community

 Overview

JUST Community is a university community web application developed to help students interact through multiple integrated services in one platform. The system provides features for cafeteria meal ordering, student marketplace posting, lost and found management, and administrative approval functionalities.

The project was developed using PHP, MySQL, HTML, CSS, and JavaScript.

---

Main Features

1-User Authentication

* User registration and login
* Secure session handling
* Input validation

2- Cafeteria Ordering System

* Browse cafeterias and meals
* View meal details and prices
* Place food orders with quantity selection

3- Student Marketplace

* Publish products for sale
* Browse student posts
* Admin approval for published items

4- Lost & Found System

* Add lost or found items
* Upload item descriptions and images
* Browse posted items

5- Admin Module

* Approve or reject marketplace posts
* Manage cafeteria requests
* Monitor system activities

## Database

The system uses a MySQL relational database to manage:

* Users
* Meals
* Cafeterias
* Orders
* Product
* Product Requests
* Lost & Found Items

---------------------------------


 Installation Guide

1. Install XAMPP.
2. Place the project folder inside the `htdocs` directory.
3. Start Apache and MySQL from XAMPP Control Panel.
4. Import the database SQL file using phpMyAdmin.
5. Open the project in the browser using:

```text
http://localhost/project-folder-name
```
